# 怪異捜査ファイル（プロトタイプ）

日本の妖怪・怪異を調査するファスモフォビア風スマホゲームの企画書＋Webプロトタイプです。
このディレクトリは `blogger-x-bridge` リポジトリ内の独立したサブプロジェクトで、Blogger→X投稿ツール本体とは無関係です。

- 企画書: [`docs/GDD.md`](docs/GDD.md)（コンセプト、調査システム、経済設計、課金設計の3案比較、ロードマップ）
- プロトタイプ: [`web/`](web/)（ビルド不要のバニラHTML/CSS/JavaScript）

## プロトタイプの遊び方

```
cd game/web
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

`index.html` を直接ブラウザで開くだけでも動作します。

## 実装済みの内容
- 依頼選択→現地調査（**一人称視点でのリアルタイム探索**・8種の証拠・道具マッチング）→正体特定→報酬受取のコアループ
- 調査パートはレイキャスティング方式の疑似3D（Canvas 2D、外部ライブラリ不使用）。PCはマウス視点操作＋WASD移動＋Eキーで調べる、スマホはタッチ操作（初期設定では画面左半分ドラッグで移動、右半分ドラッグで視点操作。設定画面で左右入れ替え可能）に対応。移動スティックは指を触れた位置が基準（触れた瞬間はニュートラルで、上下左右のドラッグがそのまま前後左右の移動に対応）
- 調査画面は横画面フルスクリーン表示（画面全体を覆う固定表示、上部のタブ類は隠れる）。縦向きで開くと横向きを促す案内が出て、その間はタイマーも停止する
- 調査画面はバトルロイヤル系スマホゲーム風に、道具選択・ジャーナル・正体特定・撤退をすべて画面内のアイコンボタンで操作できるUIに統一
- 設定画面（操作スティックの左右配置、マウス／タッチ視点感度、視野角(FOV)、襲撃演出のON/OFF、セーブデータリセット）を追加
- サニティ／制限時間の管理と、ランクに応じた「脅かしイベント」
- 各依頼には見えない「危険な部屋」が1つ設定されており、そこを調べると一定確率でその妖怪本人に名指しで襲われる（画面フラッシュ・揺れ・警告テキストの演出、大幅なサニティ／時間ダメージ、行動不能になる短いスタン、致命傷なら強制送還）
- 舞台（旅館／洋館／神社）ごとに間取り・壁の質感・天井床の配色・UIのアクセントカラーが変わる。旅館は廊下を軸に部屋が並ぶ王道の間取り、洋館は玄関ホールを中心に部屋が放射状に繋がるハブ型、神社は参道の奥に本殿がある一本道型（それぞれ洋館ミステリ／和風ホラーの定番構成を参考にしたもの）
- 壁のテクスチャ（旅館＝木目、洋館＝石積み、神社＝朱塗りの木目）はCanvas上でプロシージャル生成（外部画像素材は不使用）し、レイキャスティングで実際に貼り付けている
- 歩行中は視点がわずかに揺れ（ヘッドボブ）、画面右下に手と選択中の道具アイコンを表示。道具を使う（部屋を調べる／セーブポイントで休む）と手が持ち上がる演出が入る
- 各マップの拠点（スポーン地点）に「セーブポイント」を設置。近づいて調べると（旅館＝駐車場の車、洋館＝門前の車、神社＝鳥居前の車）、時間を消費してサニティを回復できる
- 天井にも舞台ごとのプロシージャルパターン（格天井風の梁など）を重ねて、屋外ではなく室内にいることが分かるようにした
- マウス／タッチのドラッグ、矢印キー上下で上下の視点（見上げ・見下ろし）にも対応。実装は画面全体を上下にずらす「Yシアリング」方式（Build/DOOM系エンジンでよく使われる簡易的な上下視点表現）
- 霊符ポイントでの道具購入・消耗品購入（道具屋）
- レベルアップで出現する妖怪が増える仕組み（Lv1で3種→レベル毎に+1種、全15種）
- 妖怪図鑑（未解放は？表示、発見済みは詳細フレーバー解放）
- 課金要素のモック画面（リワード広告・広告除去・シーズンパス・ジェム購入・コスメガチャ）
  **実際の決済処理は行っていません。** すべてボタン操作で即時にデモ付与されます。

## 実装していない内容（企画書のロードマップ参照）
- サーバー・アカウント機能（データは `localStorage` のみ）
- 実際の決済・広告SDK連携
- デイリー/ウィークリーミッション、マルチプレイ
- 本番品質のアート・SE・BGM
