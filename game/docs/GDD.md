# 企画書：怪異捜査ファイル（Kaii Sousa File）

日本の妖怪・怪異をテーマにした、Phasmophobia風の「現地調査×正体特定」スマホゲーム企画書。

> 本ドキュメントは検討用のたたき台です。特に「課金設計」の章は要相談前提でA/B/C案＋推奨案を提示しています。

---

## 1. 概要

| 項目 | 内容 |
|---|---|
| タイトル（仮） | 怪異捜査ファイル -Kaii Sousa File- |
| ジャンル | 一人称探索×推理（怪異調査シム） |
| プラットフォーム | iOS / Android（スマホアプリ） |
| プレイ人数 | シングルプレイ（将来的にオンライン協力を検討） |
| 参考タイトル | Phasmophobia（証拠収集→正体特定の構造を踏襲） |
| セールスポイント | 幽霊ではなく「日本の妖怪・怪異」を調査対象にすることで差別化。座敷童子、河童、雪女、ろくろ首など馴染みのある妖怪をモチーフにした証拠パターンと図鑑コンプ要素 |
| 収益モデル | 基本無料＋広告＋コスメティック課金／シーズンパス（詳細は6章） |

### コンセプト
プレイヤーは「怪異調査員」となり、依頼のあった民家・学校・廃屋・山中の祠などに赴き、そこに潜む妖怪・怪異の正体を、道具を使って集めた証拠から推理し特定する。単に道具を当てて終わりにせず、**探索の駆け引き（サニティ／制限時間／怪異の脅かし）**と**育成・収集のやり込み（図鑑・レベル・ショップ）**の両輪で継続プレイを狙う。

## 2. コアゲームループ

```
依頼選択（3件から選ぶ・ランクで難易度と報酬が変化）
   ↓
調査準備（所持道具の確認・消耗品の装備）
   ↓
現地調査（探索・証拠収集・サニティ管理・怪異の脅かしイベント）
   ↓
正体特定（図鑑の中から証拠パターンが一致する妖怪を推理して回答）
   ↓
報告・報酬受取（霊符ポイント／経験値。効率が良いほどボーナス倍率UP）
   ↓
強化（ショップで道具強化・消耗品購入／レベルアップで新しい妖怪が出現プールに追加）
   ↓
次の依頼へ（毎回マップ・証拠配置・妖怪個体をランダム生成）
```

## 3. 調査システム（やり込み要素）

単調な「道具を当てるだけ」にしないため、以下を組み合わせる。

### 3.1 証拠システム（8種）
温度低下 / EMF反応 / 足音 / 影の目撃 / 声（EVP） / 塩の異常反応 / 鏡の異変 / 御札の反応

妖怪ごとに固有の証拠3種の組み合わせを持つ（Phasmophobiaのゴースト種別と同様の「消去法パズル」）。対応する道具（温度計・EMFリーダー・ICレコーダー・暗視カメラ・盛り塩・合わせ鏡・御札・集音マイク）を正しく使わないと証拠は出ない。

### 3.2 単調にしないための仕掛け
- **毎回ランダム生成**：部屋構成、証拠の配置場所、ハズレ部屋（証拠なし）の割合を依頼ごとにランダム化。
- **サニティ（正気度）と脅かしイベント**：調査を続けるほど怪異の活動が活発化し、ランダムで「脅かしイベント」が発生してサニティを大きく削る。サニティ0で強制撤退（成功報酬は得られず、僅かな慰労報酬のみ）。
- **制限時間**：依頼ランクごとに持ち時間が異なり、素早く正体を特定するほど報酬倍率が上がる（効率ボーナス）。
- **危険度ランク（E〜SS)**：ランクが上がるほど脅かし頻度・報酬・必要な観察眼が増す。
- **図鑑コンプリート要素**：発見済みの妖怪は図鑑に生態・弱点フレーバーが解放される。全種コンプは長期目標として機能。
- **将来拡張候補**（本プロトタイプ未実装・ロードマップ）：デイリー/ウィークリーミッション、協力調査（マルチ）、季節限定の特殊怪異（期間限定イベント）。

## 4. 経済・報酬設計

| 要素 | 内容 |
|---|---|
| メイン通貨 | 霊符ポイント（調査の成功報酬、実績で獲得。ショップで道具・消耗品と交換） |
| 副通貨（課金用） | 勾玉ジェム（課金または稀に依頼報酬で少量入手。コスメガチャ・シーズンパスに使用） |
| 経験値／レベル | 調査成功でXP獲得しレベルアップ。**レベルアップの度に出現する妖怪の種類が増える**（ユーザー要望の「レベルアップでお化けが増える」を実現）ほか、高ランク依頼や新エリアが解放される |
| ショップ | 調査道具の購入・上位互換への強化、消耗品（サニティ回復のお守り、時間延長の御札など）の購入 |

### レベル解放カーブ（例）
Lv1で妖怪3種（低ランク）が調査対象プールに登場。以降レベルアップごとに1体ずつ追加され、Lv15前後で全15種が出現するように設計。高ランク妖怪ほど出現に必要なレベルが高い。

## 6. 課金設計（要相談・A/B/C案＋推奨）

ユーザーからの要望「課金要素は要相談」を受け、3方向を比較する。**Pay to Win（強さを直接買う課金）は採用しない**方針で統一（ストア評価・炎上リスクを避けるため）。

### 案A：ガチャ型（調査道具・お守りの見た目ガチャ）
- 内容：護符や道具の見た目スキンをガチャで排出。効果は同一（コスメティックのみ）。
- メリット：課金単価・継続課金率が高い。
- 留意点：**景品表示法（コンプガチャ規制・確率表示義務）、資金決済法（前払式支払手段の届出要否）**への対応が必須。ストア（Apple/Google）のガチャ確率表示要件も遵守する必要あり。

### 案B：シーズンパス（バトルパス型）
- 内容：期間限定で無料/有料の2トラックの達成報酬レーンを用意。有料トラックは購入制。
- メリット：コンプガチャ規制の対象外で健全性が高く、収益も安定しやすい。既存の霊符ポイント経済と相性が良い。

### 案C：広告＋広告除去／ブースト課金
- 内容：基本無料＋リワード広告（報酬2倍等）、広告非表示の買い切りIAP。
- メリット：導入が最も簡単で、無課金層からも広告収益を得られる。初期リリース向き。

### 推奨案：ハイブリッド（C＋Bを軸、Aは限定的に）
1. **ベースはC**：無料プレイ＋リワード広告で報酬ブースト、広告除去は買い切りIAPで提供。初期リリースの収益基盤とする。
2. **継続課金はB**：シーズンパスで進行に応じた報酬（霊符ポイント・コスメ）を段階的に提供し、LTVを伸ばす。
3. **Aは絞って採用**：コスメティック（護符・演出エフェクトの見た目のみ）に限定したガチャを、法令遵守（確率表示・天井設置・コンプガチャに該当しない設計）を前提に後日追加検討。ゲーム性に影響する道具の強さそのものはガチャ対象にしない。
4. **未成年配慮**：課金上限のペアレンタルコントロール導線、年齢確認、月次課金上限のアプリ内表示を設計に含める。

> 本プロトタイプではA/B/Cの世界観を体験できるモック画面（ストア画面）のみ実装し、**実際の決済処理は行っていません**（ボタンを押すとデモ用に即時付与されるのみ）。

## 8. 本プロトタイプの範囲・制約

- データ保存はブラウザの `localStorage` のみ（サーバー・アカウント機能なし）
- 課金・広告は全てモック（実際の決済・広告SDKは未接続）
- 3Dモデルやフル美術素材は未制作。UIはテキスト・簡易CSSでの仮素材
- デイリーミッション・マルチプレイ等は未実装（ロードマップ上の将来検討事項）
